Systems & tools

The daily screen was rebuilt around what needs a decision
The screen that opens each morning used to be a long page that had to be read end to end. It is now a short set of cards, each one a thing that actually needs an answer, and each can be marked done, put off, or handed over. Anything still unresolved comes back the next day rather than disappearing once it has been ticked.
Two screens were showing numbers that were not right
One screen was counting the weekly deposit twice, which made the cash position look better than it was; that is fixed. A second screen was found doing the same thing in a different place and is next in line. Both were found by going through the system deliberately rather than by noticing something looked odd.
Every screen in the system was reviewed
Each screen was gone through in turn, checking that what it shows is true and that the figures behind it hold up. Everything found was written down with the evidence, and the significant items were re-checked from the original records rather than taken on trust. A handful of the reported problems turned out not to be problems, and saying so is as much the point as the ones that were real.
The weekly recap now says which invoices made up a payment
When a client payment arrives it can be several invoices paid together and passed through as one deposit. The recap now names each one and what it was for, so a single figure in the bank can be traced back to the work it paid for without anyone having to go and look it up.
